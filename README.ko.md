# React Starter Template 한국어 아키텍처 가이드

이 저장소는 여러 React 서비스를 빠르게 시작하기 위한 회사 표준 템플릿입니다. 튜토리얼이나 데모 앱이 아니라, 실제 제품 개발에서 반복적으로 필요한 기반을 미리 결정해 둔 출발점입니다.

## 핵심 원칙

- 비즈니스 코드는 `features` 안에서 도메인 단위로 성장시킵니다.
- 서버 데이터는 TanStack Query가 소유하고, 클라이언트 UI 상태만 Zustand가 소유합니다.
- API 호출은 반드시 `shared/api`를 통과시켜 인증, 에러, 재시도, 취소 정책을 한 곳에서 유지합니다.
- UI 프리미티브는 재사용 가능해야 하며 특정 기능의 업무 규칙을 알면 안 됩니다.
- 설정 파일은 팀 전체의 품질 기준이므로 개인 취향보다 일관성과 자동화를 우선합니다.

## 수정할 때의 기준

새 기능을 추가할 때는 먼저 해당 기능이 어떤 도메인에 속하는지 결정하세요. 예를 들어 사용자 초대, 권한 변경, 사용자 목록은 `features/users`에 둡니다. 여러 기능에서 재사용되는 순수 유틸리티나 UI 프리미티브만 `shared`로 승격합니다.

공통 코드를 만들기 전에 같은 문제가 적어도 두 곳 이상에서 반복되는지 확인하세요. 너무 이른 추상화는 템플릿을 어렵게 만들고, 너무 늦은 추상화는 기능 폴더를 중복으로 오염시킵니다.
